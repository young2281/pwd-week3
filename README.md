# 3주차 과제 : 계산기

## operations

사칙 연산 함수 (+, -, x, /, =)

## calculator

상태 처리

## app

버튼 클릭 이벤트 처리, 렌더링

### 기본 사칙연산

| 입력                | 결과  | 담당 코드                                               |
| ------------------- | ----- | ------------------------------------------------------- |
| `12 → + → 3 → =`    | `15`  | `operations.ts`의 `add`                                 |
| `12 → − → 3 → =`    | `9`   | `operations.ts`의 `subtract`                            |
| `12 → × → 3 → =`    | `36`  | `operations.ts`의 `multiply`                            |
| `12 → ÷ → 3 → =`    | `4`   | `operations.ts`의 `divide`                              |
| `0.1 → + → 0.2 → =` | `0.3` | `calculator.ts`의 `formatNumber` (부동소수점 오차 정리) |

### 편집·표시 기능

| 입력      | 결과        | 담당 코드                                      |
| --------- | ----------- | ---------------------------------------------- |
| `123 → ⌫` | `12`        | `calculator.ts`의 `handleKey`(`delete` 분기)   |
| `5 → +/−` | `-5`        | `calculator.ts`의 `handleKey`(`sign` 분기)     |
| `50 → %`  | `0.5`       | `calculator.ts`의 `setResult` (100으로 나누기) |
| `6110000` | `6,110,000` | `app.ts`의 `formatDisplay` (천 단위 콤마)      |

### 계산식 표시와 초기화

- `AC → 1 → 2 → +` 입력 시 위쪽에 `12 +` 표시, `3` 입력 시 `12 + 3`, `=` 입력 시 `12 + 3 =`와 결과 `15` 표시 → `calculator.ts`의 `pendingExpression`이 계산식 문자열을 만들고, `app.ts`의 `render`가 `#expression`에 반영.
- 결과가 나온 뒤 새 숫자를 누르면 계산식이 지워지고 새 입력 시작, `AC`는 전체 초기화 → `calculator.ts`의 `inputDigit`/`clear`.

### 오류와 복구

- `AC → 1 → 2 → ÷ → 0 → =` 입력 시 화면에 `Error`와 "0으로 나눌 수 없습니다." 메시지 표시 → `operations.ts`의 `divide`가 예외를 던지고, `calculator.ts`의 `handleKey`가 `catch`로 잡아 `state.error`에 저장, `app.ts`의 `render`가 `#message`에 출력.
- 이후 숫자를 누르면 오류가 지워지고 새 입력 시작 → `calculator.ts`의 `inputDigit` 첫 줄(`if (state.error) clear()`).

### 연속 입력

| 입력                    | 결과    | 설명                                          |
| ----------------------- | ------- | --------------------------------------------- |
| `2 → + → 3 → × → 4 → =` | `20`    | 입력 순서대로 계산 (`(2+3)×4`)                |
| `2 → + → × → 3 → =`     | `6`     | 마지막에 선택한 연산자(×)가 적용됨            |
| `200 → + → 10 → % → =`  | `200.1` | `%`는 현재 입력 숫자만 100으로 나눔           |
| `2 → + → =`             | `2`     | 두 번째 숫자 없이 `=`를 누르면 대기 상태 유지 |
| `2 → + → 3 → = → =`     | `5`     | 반복 `=`는 계산을 다시 실행하지 않음          |
